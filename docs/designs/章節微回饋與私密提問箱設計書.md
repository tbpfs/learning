# Python 互動教學站（`learn.ai-purplemaple.com`）章節微回饋、私密提問箱與統一收件匣設計書

## 1. 背景與目標

為強化 `learn.ai-purplemaple.com` 七大獨立章節講義（`ch01.html`～`ch07.html`）的讀者互動品質與長尾 SEO FAQ 飛輪，同時維持 `tbpfs/learning` 靜態 GitHub Pages（零後端執行環境）與「版面不變花、零公開 UGC 垃圾留言」原則，將替代留言方案 1＆2 落地於以下目標：

1. **極簡章節微回饋（方案 1）**：於 `ch01.html`～`ch07.html` 文末面試 FAQ 下方、文末廣告與分頁導覽之前掛載「這篇講義對你有幫助嗎？👍／👎」微回饋卡（`index.html` 課程總覽維持純淨不掛載）；點選後才展開單行選填文字框（最多 200 字），不公開渲染至網頁。
2. **收合式私密提問箱（方案 2）**：微回饋列下方配置預設收合之「還有程式觀念卡關？匿名提問給紫楓（整理進本章 FAQ）」，匿名收集讀者實戰疑問，經站長審閱查證後補入對應章節的 `InterviewFAQ` 與 `FAQPage` JSON-LD。
3. **跨站私有 GCS CAS 儲存與統一審閱台（`ai-purplemaple.com/inbox.html`）**：複用既有 `aily-portfolio` Cloud Run 服務與 `CMS_API_KEY`，將 `learn` 回饋與提問經嚴格 `Origin` 白名單（僅允許 `https://learn.ai-purplemaple.com` 與 `https://ai-purplemaple.com`）寫入私有 GCS 貯體 `gs://aily-releases-private-gen-lang-client-0649311710/learn-feedback/state.json`，並於 `https://ai-purplemaple.com/inbox.html`（`noindex, nofollow`）提供同時切換檢視／刪除 `learn` 與 `waifuscan` 回饋之單一收件匣。
4. **生態系資訊一致性修正**：順手同步更新頁尾與 `llms.txt`／`llms-full.txt` 對 `muse.ai-purplemaple.com` 之描述為 Meta Muse 邀請碼分享站，並於隱私政策聲明揭露匿名回饋處理機制。

## 2. 方案比較與取捨（Alternatives Considered）

| 評估維度 | GitHub Discussions / Giscus 公開留言外掛 | 本案採用：站內極簡表單 ＋ 主站私有 GCS CAS 後端 |
| :--- | :--- | :--- |
| **讀者門檻與隱私** | 強制讀者必須擁有並登入 GitHub 帳號，不利新手匿名提問；公開紀錄留在 GitHub | 零登入要求，直接匿名回饋或提問；原始 IP 僅經 HMAC-SHA256 單向雜湊限流，不落地也不公開 |
| **SEO 與廣告干擾** | iframe 外掛載入肥大、無法控制低品質或過期留言對頁面主題的影響 | 原生輕量 HTML/CSS 約十餘個 DOM 節點，總節點遠低於 `1,500` 上限；高頻提問經整理轉為官方結構化 FAQ 放大 SEO |
| **多專案憑證管理** | 每開一站就要多申請一組資料庫或新密鑰 | 零新增雲端密碼、零開 Firestore：複用主站既有 `CMS_API_KEY` 與既有具 `objectAdmin` 權限之私有 GCS 貯體 |

## 3. 系統架構、資料流與不變量

### 3.1 靜態端點與安全邊界（`learning` ＋ `antigravity-portfolio_site`）

| 元件／端點 | 存取控制與驗證 | 限流、防濫用與持久化 |
| :--- | :--- | :--- |
| `ch01.html`～`ch07.html` (`#fbBox`) | 僅單章講義頁渲染；`index.html` 不出現；`aria-pressed`、`localStorage`（`try/catch` 包裝）與重複點擊免重扣配額 | 錯誤顯示紅字 `.err`；空白折疊 `< 5` 字前端攔截並聚焦；行動版 `< 640px` 輸入框 `16px` 防 iOS 縮放 |
| `OPTIONS` / `POST /api/v1/learn-feedback` | **嚴格 `Origin` 白名單**（僅 `https://learn.ai-purplemaple.com` 與 `https://ai-purplemaple.com`；遺漏、`null` 或跨站皆回 `403`，**絕不輸出 `*`**）；`GET` 回 `404` | 負載上限 `4096` bytes 且須為 JSON 物件；蜜罐 `website` 回 `200` 不入庫；`slug` 白名單限 `ch01`～`ch07`；`vote` 嚴格為 `1` 或 `-1`（排除 `bool`）；備註空白折疊裁切 `200` 字；每日每雜湊 IP 限 `10` 次 |
| `OPTIONS` / `POST /api/v1/learn-question` | 同上嚴格 `Origin` 白名單；`GET` 回 `404` | 空白折疊後長度 `< 5` 回 `400 too_short`、`> 400` 回 `400 too_long`；蜜罐 `website` 回 `201` 不入庫；每日每雜湊 IP 限 `3` 次 |
| `GET /api/v1/inbox?site=...` & `DELETE /api/v1/inbox/...` | 須帶有效 `Authorization: Bearer` 或 `X-Grok-Api-Key`（未通過回 `401`）；若帶 `Origin` 須符合同源／白名單（否則 `403`） | 支援 `site=learn`（`learn-feedback/state.json`）與 `site=waifuscan`（`waifuscan-feedback/state.json`）；刪除寫入 `deleted_notes`／`deleted_questions` 墓碑並清除空殼 |
| `/inbox.html` | `Cache-Control: no-store`、`X-Robots-Tag: noindex, nofollow`、`robots.txt` 加入 `Disallow: /inbox.html`、不進 `sitemap.xml` | 前端全程以 `document.createElement`＋`textContent` 渲染（零 XSS） |

### 3.2 GCS `ifGenerationMatch` CAS 樂觀鎖與 CRDT 併發不變量

1. 讀寫 `gs://aily-releases-private-gen-lang-client-0649311710/{site}-feedback/state.json` 一律攜帶物件版本號（`X-Goog-Generation` / `ifGenerationMatch`）；遇 HTTP 412 併發衝突時於 `_mutate_feedback_site()` 自動重新讀取最新遠端狀態並重跑 `mutator`（最多 4 次），確保同站或跨服務（如 `waifuscan` 寫入與 `/inbox.html` 刪除）絕不互相覆蓋，且不重複扣減每日限流；另提供 `merge_feedback_state()` 作為多來源／離線快照之 CRDT 無損合併函式。
2. `prune_feedback_state()` 定期清除超過 30 天的刪除墓碑與過期限流桶，單頁保留最新 `500` 筆投票、全站保留最新 `200` 筆備註與 `200` 筆提問，並自動刪除 `{votes:{}, notes:{}}` 空殼鍵。
